BHX MEDIA - WEBSITE KIT (Soft Turmeric + Ink, option Y4c)

FILES
  BHX_website_colours.png ...... colour sheet + homepage sample (share with designer)
  bhx_colours.css .............. paste into the website stylesheet (CSS variables)
  bhx_colours.json ............. same colours for Framer / Figma / Webflow
  logos_for_yellow/ ............ logo with laterite bindu, for use ON the yellow background

RULES
  - Page background: Soft Turmeric #F6DE9A. Inner reading pages: Cream #FAEBC4.
  - Buttons and links: Laterite #7A3E2B with Paper text.
  - Dark bands / footer: Ink #1C1A17; use Turmeric #E0A21B only for highlights there.
  - Never use Turmeric for text on yellow or cream (unreadable).
  - On yellow use the logo files in logos_for_yellow/. On ink bands use the normal paper logo.
  - Font: Bricolage Grotesque (free, Google Fonts).
